# MOAMLIGHT 3D Model Asset Directory

Place your 3D `.glb` models here:

- **`flower-candle.glb`**: 
  The 3D model for the **Artisan Lotus Candle - Sea Spray & Jasmine**.
  - Format: Binary GLTF (`.glb`)
  - Target size: strictly under 3MB to 5MB (web-optimized)
  - Origin: Centered at (X: 0, Y: 0, Z: 0) at the bottom base of the dish
  - Materials: PBR Metallic Roughness (Gold dish: `metalness: 0.95`, `roughness: 0.2`)

When `flower-candle.glb` is placed directly in this `public` folder, the 3D viewer in MOAMLIGHT will automatically detect and render your custom `.glb` model with the `<Float>` antigravity bobbing effect and live custom engraving text!
